📘 SkillSphere Academy
SkillSphere Academy is a responsive educational and training website designed to provide information about courses, internships, registration, and contact details. The project focuses on building a clean and user-friendly UI for an academy platform.
This version is deployed using GitHub Pages as a frontend-only website, meaning it runs without a backend server.

🛠 Tech Stack
HTML

PHP (used in original backend version)
MySQL (used in original backend version)

⚙️ Features
🏠 Home page with academy introduction
📚 Courses and internship details section
📝 Registration form UI
📞 Contact page
🎨 Responsive design for all devices
🧭 Navigation bar with multiple pages

This project originally included backend functionality using:
PHP for server-side processing
MySQL for database storage (registration data)
However, since GitHub Pages does not support backend technologies, this version has been converted into a static frontend website.
👉 The backend version can be run locally using XAMPP or hosted on PHP-supported platforms.
